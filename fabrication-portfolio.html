Key Fabrication Insights

Parametric Sizing: Using SolidWorks smart dimensions ensured the inner diameter accounted for paper cup taper angles for a friction fit without sliding.
DXF Kerf Offset: Exporting direct DXF profiles allowed the Epilog laser to cut smooth, flame-polished petal radii without manual deburring.
Thermal Ductility: Controlled heat gun application enabled progressive manual bending along the handle neck without causing acrylic stress-bleaching.

Molding & Casting Technical Takeaways

Parting Line Control: Accurately leveling the clay bed prevented undercut lockups and ensured smooth part removal from both silicone halves[cite: 3].
Mold Release Application: Thorough aerosol release coating prevented the second silicone pour from bonding permanently to the cured first half[cite: 3].
Resin Hydrostatic Head: Using an extended straw feed created enough liquid pressure to push resin into tight internal radiuses without void entrapment[cite: 3].
