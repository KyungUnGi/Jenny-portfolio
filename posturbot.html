PosturBot

Phase: Active Prototype / Validation

Dual-IMU Cervical Posture Monitor for Tech Neck Mitigation

ESP32-C3 2x MPU-6050 IMUs SolidWorks CAD Web Bluetooth (BLE) Complementary Filter

System Architecture Overview

PosturBot replaces unreliable single-sensor chest/spine monitors by calculating the relative angle between two dynamic IMU nodes: one reference node behind the neck and one ear-mounted tracking node.

  • Non-adhesive, ergonomic ear hook fit eliminating skin irritation.
  • Real-time relative cervical angle estimation with zero drift calibration.
  • Wireless BLE telemetry transmitting live data to a customized Web Dashboard.

Electrical System & Schematics

Circuit architecture linking dual I2C sensors and power regulation to the ESP32-C3 microcontroller.

Dual I2C Communication Architecture

The hardware configuration manages two MPU-6050 6-axis IMU sensors over a shared I2C bus by configuring unique hardware addresses (`0x68` for ear node and `0x69` for neck reference node).

  • ESP32-C3: Handles high-frequency IMU polling and Web Bluetooth broadcasts.
  • Power Delivery: Integrated LiPo battery power step-down with low-noise filtering for IMU stability.

Web Bluetooth (BLE) Telemetry & Software

Real-time wireless communication and data visualization interface.

Live Posture Monitoring Interface

Built using standard Web Bluetooth APIs to connect directly to the ESP32-C3 without requiring native mobile app installations.

  • Complementary Filtering: Fuses accelerometer and gyroscope data to filter out body movement noise.
  • Visual Alert Triggers: Flags forward head posture ("Tech Neck") when relative angle exceeds customizable ergonomic thresholds.
